# Machine Learning-Based Banknote Authentication Using Classification Algorithms

## 📌 Project Overview
This project focuses on classifying banknotes using machine learning classification algorithms. It uses numerical features extracted from banknote images to predict the class of a banknote. The project demonstrates data analysis, preprocessing, model training, evaluation, and performance comparison.

## 🎯 Objectives
- Understand and analyse the banknote authentication dataset.
- Perform exploratory data analysis (EDA).
- Identify missing values, duplicates, and feature relationships.
- Implement multiple machine learning classification algorithms.
- Evaluate and compare model performance.
- Identify the best-performing model based on evaluation metrics.

## 📂 Dataset
**Dataset Name:** Banknote Authentication Dataset

**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/267/banknote+authentication)

The dataset contains four numerical input features:

- Variance
- Skewness
- Curtosis
- Entropy

**Target Variable:** Class
